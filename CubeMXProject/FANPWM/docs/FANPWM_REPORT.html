FANPWM 專案报告（標題 / 子標題 / 說明 / 圖表數據）

STM32G4 風扇閉迴路控制專案總整理。包含目標、流程、方法、进度、测试結果，並以圖表與測試數據佐證。

1. 專案目標

1.1 主目標

  • 建立 STM32G4 風扇的 PWM / RPM / 風速關係。
  • 完成閉迴路 RPM 控制驗證。
  • 量化 target、actual、duty、ff、integral、ripple。

1.2 副目標

  • 建立可重現測試流程。
  • 將韌體、資料、腳本與報告版控。
  • 建立 auto/manual 切換与可追蹤分析 pipeline。

2. 系統流程

2.1 初始化

  • HAL_Init / SystemClock / peripherals
  • TIM1 / TIM8 / TIM2 / GPIO
  • fan_control_init() / rpm_ctrl_init() / rpm_sweep_init() / button_ui_init()

2.2 主迴圈

  • rpm_ctrl_update() / rpm_sweep_update()
  • rpm_ctrl_uart_poll() / button_ui_poll()
  • CSV / status periodic logging

2.3 Method B 模式切換

  • A0 stop auto sweep，進入 manual UART mode
  • A1 enable auto sweep
  • A toggle on/off

3. 控制方法

3.1 Feedback Control

  • target from UART: R<rpm> / P<pct>
  • actual RPM from tach
  • feedforward + PI correction
  • target ramp, filtering, anti-windup

5. 測試協議

5.1 固定 protocol

  1. Send A0
  2. P25 hold 30s
  3. P50 hold 30s
  4. P75 hold 30s
  5. P25 hold 30s
  6. 重复 3 次

5.2 acceptance criteria

  • Steady-state error：±5%
  • Overshoot：< 15%
  • Settling time：< 2s
  • 3-repeat CV：< 10%
  • RPM ripple minimal

8. 问题与根因

8.1 Overshoot

  • P50→P75 ~13-18%
  • 仅 at spec boundary
  • likely Ki + feedforward transition

8.2 Settling Time

  • P25→P50 ~4.4-4.8s
  • spec 2s
  • 说明 system second-order lag + integral re-build

8.3 Low RPM

  • 417 RPM FF error 7.86%
  • tach ripple at low duty
  • calibration density insufficient

9. Next Actions

  • Keep V2 as effective baseline.
  • Next Ki decrement only: 0.45 -> 0.40.
  • Low RPM P10/P15/P20 FF refinement.
  • Repeat protocol 3 times and append Run metrics.
  • Commit only validated firmware + docs.
