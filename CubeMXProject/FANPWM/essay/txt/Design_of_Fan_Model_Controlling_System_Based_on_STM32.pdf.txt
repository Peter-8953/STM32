Abstract—The paper describes the implementation of a control 
system based on STM32 microcontroller, which was selected to 
control the laboratory model of the fan. First, a mathematical 
model was identified and then the design of the parameters of the 
digital PID controller was tuned using the desired model method. 
In the KEIL µVision environment, program functions for this 
control process were created and tested in real time. 
Keywords—PID controller, laboratory fan model, KEIL, 
microcontroller, process control, STM32 
I. INTRODUCTION 
The development of microelectronics and the efforts of 
miniaturization offer microcontrollers with minimal 
dimensions, which thus become much more interesting for use 
in practice.  In addition to digital or analog inputs and outputs, 
microcontrollers also include many variants of interfaces and 
auxiliary processors, such as CAN, I2C, SPIO, Bluetooth, 
Ethernet, Wi-Fi, etc. [1] In the case of peripherals, counters, 
timers and DMA are also important parts. [2] Besides, they 
contain a specialized mathematical coprocessor, which is 
designed to calculate floating point operations. 
STMicroelectronics microcontrollers become quite famous 
among engineers for their low power consumption and sheer 
computational power [3]. They are manufactured in several 
levels of equipment and thus it is possible to choose the most 
suitable model for a specific real deployment. 
The advantage of using microcontrollers is, among other 
things, their implementation in close proximity to the sensor and 
thus guarantees less signal disturbance when obtaining a signal 
from these technical means than when transmitting an analog 
signal to a remote computer for further processing. [4] 
The application areas of microcontrollers currently represent 
embedded systems, e.g. for mobile devices [5], self-care 
systems, smart home systems [6]. In the field of artificial 
intelligence, the STM32 series microcontrollers also have 
support in the specific model STM32Cube.AI [7], which is 
being developed to create and map of the neural networks for 
person presence detection, safe driving systems [8] and many 
other useful applications. 
The intention was to use the microcontroller of the STM32 
series for the regulation of the laboratory model and to compare 
it with the existing solution of the control system inside 
the computer using the National Instrument measuring card. 
The goal is to implement algorithms of a digital PID controller 
into an STM32 microcontroller. In the future, adaptive control 
algorithms are applied in the next work, or adaptive control is 
implemented using an orthogonal neural network, assuming 
the type of selected microcontroller and limiting the size of its 
memory. [3] 
II. MICROCONTROLLER SELECTION 
Selecting suitable microcontrollers for control system 
applications is often a crucial task. For most applications, 8-bit 
microcomputers that are well documented are sufficient. Over 
the years, a number of development tools and software have 
emerged to help expand these microcomputers.  
32-bit microcomputers are now increasingly used for their 
computing capabilities and ever-decreasing cost, so they are 
available to a wide range of end users. One of the groups  
of 32-bit microcomputers are microcomputers based on 
the STM32 architecture. [2] For the control of the laboratory fan 
model, it would be possible to choose other microprocessors, but 
the secondary interest was to gain experience with more 
powerful microprocessors for the later application of more 
complex control algorithms. Based on the requirements and 
technical equipment, a microcontroller of the STM32 series was 
selected. 
The well-known type of laboratory model, namely the fan 
model, was chosen by the controlled system. This lab model can 
easily communicate with a computer using a National 
Instrument USB-6009 14-bit multifunction data acquisition 
USB device. [10] There is software support in the graphical user 
application implemented in LabView, and applications 
in the MATLAB environment have also been created before. 
Now the fan model is controlled by a microcontroller and 
the functions necessary for obtaining, adjusting and setting 
the input-output parameters of the control process are 
implemented.

B. Developlment Environment for STM32 
Support for Integrated Development Environments (IDEs) 
for STM32 Microcontrollers is extensive. The basic division is 
into freely available (free IDEs) or IDEs for commercial use. 
Free IDEs include, for example, KEIL µVision, Atollic True 
STUDIO, STM32Cube, System Workbench for STM32. [9] 
The KEIL µVision environment was applied, which enables 
overall project management, a source code editor and 
a debugger. In particular, µVision Debugger provides a unified 
environment for testing the developed application, debugging 
possible errors and optimization. Controlled code execution is 
a great support for program development, including 
the possibility of a full view of the state of peripherals. The 
freely available DK-Lite license is limited to the development of 
the program up to 32 Kb. Also, the compiler and linker do not 
generate independent code and data. The reason for choosing 
IDEs KEIL is, in addition to the well-arranged development 
environment, also a module for debugging with the ability to 
connect the microcontroller using ST-LINK and the possibility 
of using the basic structure of the program generated by the 
STM32CubeMX utility with individual peripherals settings. [2] 
Debugging the program in the KEIL µVision 5 environment 
when communicating with the Nucleo board does not allow 
displaying the content of variables, which is important for 
monitoring partial variables and their course over time. 
Therefore, the open-source software called STM Studio offered 
by STMicroelectronics was used. STM Studio is designed for 
debugging applications and provides various graphical views for 
debugging and diagnostics. In the STM Studio environment, 
users can monitor the content of variables in a defined list or it 
is possible to display these variables in a graph depending on the 
time, or it is possible to display both types of display.  
III. LABORATORY MODEL FOR CONTROL SYSTEM 
We applied the control process using the STM32 
microcontroller to a laboratory model of a fan (Fig. 2), which 
was constructed in a larger number of pieces in order to teach 
students in the field of automation. 
A. Description of Laboratory Fan Model 
The construction of the laboratory model is simple and 
robust so that the model is failure-free and easily portable within 
the teaching. 
The laboratory model of the fan represents a simple type of 
controlled system, on which it is possible to test algorithms of 
measurement, identification, various types of controls, 
examination of other signals in the frequency domain, etc. 
The basis of the model is a fan with a diameter of 11 cm, to 
which an accelerometer and additional electronics are attached 
to ensure the adjustment of the supply voltage to the range 0 to 
12 V. Speed measurement can be detected by two sensors 
reflection sensor or Hall probe integrated in the fan body. The 
model is powered by voltage from the computer's USB port. [10] 
 
Fig. 2. Laboratory Fan Model for Control of Speed 
B. Electronic Development Board of Laboratory Fan Model 
An additional electronic development board mounted on top 
of the centre of the fan rotation allows the electrical signals to 
be adapted and adjusted between the laboratory model of the fan 
and the National Instrument USB-6009 measuring card. For our 
specific fan speed control purposes, we are interested in the 
description of the analog input and analog output. The analog 
output of the development board is a DA converter. The voltage 
range of the measuring card 0 to 5 V is converted to the range 0 
to 12 V and the fan is supplied with this voltage. 
An analog input of the electronic development board, which 
is output from the reflection sensor and indicates the voltage 
from the reflection sensor measuring the distance of the blade

C. Connection STM32 Nucleo-144 development board with 
Laboratory Fan Model 
The laboratory model of the fan, including the additional 
electronic development board, is powered by the USB port with 
a voltage in the range of 0 to 5 V. [10] The STM32 Nucleo-144 
development board includes a DA converter whose output 
voltage is in the range of 0 to 3.3 V. [1] Therefore, it was 
necessary to adjust this range to the range of 0 to 5 V using 
additional electronics that use an operational amplifier in a non-
inverting circuit. 
The original educational model of the fan communicates 
with the computer using a NI USB-6009 measuring card, which 
has a dead band in the range of supply voltage from 0 to 1.2 V, 
which means that the fan has no speed. For better accuracy, 
adjusting the signal to a range of 0 to 3.3 V (STM32 
Nucleo-144) removes the dead band, so this range corresponds 
to the original voltage range of 1.2 to 5 V (NI USB-6009). [10] 
The fan speed are given by the width of the pulses that are 
obtained from the reflection sensor. The reflex sensor provides 
more accurate information about fan speed than the built-in Hall 
sensor. It is also necessary to consider that the fan has 7 blades, 
so it is necessary to take this circumstance into account when 
recalculating its revolutions. The measurement signals of both 
speed sensors from the oscilloscope are shown in Fig. 3, the 
reflection sensor is shown by a yellow line, the Hall probe by a 
blue line.  
 
Fig. 3. Measurement of speed using an oscilloscope. 
Although a reflex sensor is more accurate for determining 
fan speed, it is not obvious at first glance because the signal also 
contains noise. The fan is composed of seven blades, so when 
evaluating the periodic signal obtained from the reflection 
sensor, it is necessary to correctly determine the resulting speed 
of the laboratory fan model. 
The signal of the measurement fan speed is rectangular in 
shape with an amplitude of 5 V and its frequency ranges from 
24 to 40 Hz. This signal does not correspond to the required 
range of 0 to 3.3 V for the microcontroller, therefore the signal 
was modified by the designed electronic circuit (Fig. 4). To the 
left of this electronic circuit is a Schmitt flip-flop, which is an 
inverting amplifier with hysteresis. In the middle part, an 
inverting amplifier is included so that the output signal is not 
inverted relative to the input, only its level is adjusted. 
Furthermore, a transistor is included in the right part, which 
switches the voltage to 3.3 V and thus adjusts the level to TTL. 
 
Fig. 4. Electronic circuit for signal processing from the reflection sensor. 
The measurement of revolutions was provided by a interrupt 
of the external counter. The signal from the reflection sensor is 
between 50 and 170 mV and its frequency is from 80 to 140 Hz. 
This signal also has modulated noise, so it is important to 
evaluate it correctly. 
In the program code, which was called by the interrupt signal 
from the counter, the fan revolutions were determined from the 
signal period of the reflection sensor. The sampling time was 
2 ms. Adverse speed fluctuations at constant excitation voltage 
were programmatically adjusted by averaging the previous 
samples.

VI. CONCLUSION 
Thus, the digital PID controller implemented in the STM32 
microcontroller provides a stable control of the physical model 
by calculating a controller output signal that depends on present 
and past errors in the closed loop control system. 
During the implementation of the control process, it was 
necessary establish the particular electronic circuit to adapt the 
controller output signal from the Nucleo-144 development 
board with STM32 series processor to the controlled laboratory 
fan model, specifically to the input of its electronic circuit 
providing the input-output communication. 
In the KEIL µVision environment, a program function for 
determining the fan speed from data obtained from the reflection 
sensor and a function for controlling the fan speed were 
compiled. By identifying the laboratory fan model by the three-
point approximation method, the transfer function was 
determined and then the parameters of the digital PID controller 
were designed by the desired model method. The control system 
was capable of react correctly to the change in the input voltage, 
the course of the fan speed was achieved without overshoot. 
Control of the laboratory model using STM32 
microcontroller is an intermediate step for further research in the 
field of microcontroller application to the adaptive control task 
using neural networks.
